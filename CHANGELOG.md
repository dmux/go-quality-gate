# Changelog

All notable changes to this project are documented in this file.

## [Unreleased]

### Fixed

- The Go format check generated by `--init` never failed: `gofmt -l` exits 0 even when it lists unformatted files. The template now fails when the listing is not empty (and on syntax errors) and prints the files. Configs generated by earlier versions must update the command by hand, e.g. `out=$(gofmt -l {files}) || exit 1; test -z "$out" || { echo "$out"; exit 1; }`.
- `--init` now escapes double quotes and backslashes in the generated `quality.yml`, which previously produced invalid YAML for commands containing them.

## [1.4.3] - 2026-11-24

### Added

- Changed-files analysis by default: hooks can use `{files}` and `{dirs}` placeholders and a `glob` filter, so pre-commit only checks the staged files (pre-push, the files changed since the upstream). Hooks whose glob matches no changed file are skipped and count as passed. Hooks without placeholders or globs run as before.
- `--all` flag, `QG_SCOPE=all` and `settings.scope: all` for a full analysis of every tracked file. The MCP `run_quality_checks` and `run_auto_fix` tools take an optional `scope` argument.
- `--output=json` reports the run's `scope` and `skipped` / `skip_reason` per hook; the watermark trailer lists skipped hooks (`skipped=N`).

### Changed

- `--init` templates now check only changed files (`gofmt -l {files}`, `ruff check {files}`, `npx prettier --check {files}`, `go test {dirs}`…), use `gitleaks git --pre-commit --staged` and `golangci-lint run --new-from-rev=HEAD`, and run `go test ./...` on pre-push.
- The embedded `ui` dashboard is rebuilt with the updated web dependencies; it had shipped the original Next.js runtime since it was added.
- Dependabot now opens its PRs against `develop` and also covers Go modules and GitHub Actions; `build-test.yml` uses Go 1.25 like the other workflows.

### Dependencies

- `github.com/mark3labs/mcp-go` v0.56.0 → v1.6.0 (no API changes needed).
- `golang.org/x/term` v0.1.0 → v0.45.0, `golang.org/x/sys` v0.5.0 → v0.47.0, `golang.org/x/text` v0.14.0 → v0.41.0 — the last releases that support Go 1.25, so the minimum Go version stays 1.25.5.
- `fatih/color` 1.19.0, `mattn/go-colorable` 0.1.16, `mattn/go-isatty` 0.0.24, `spf13/cast` 1.10.0, `google/jsonschema-go` 0.4.3, `santhosh-tekuri/jsonschema/v6` 6.0.3.
- Web dashboard: `next` 16.4.6 (fixes the open Next.js security advisories), `@testing-library/jest-dom` 8, `jsdom` 31, `vite` 8.3.8, `vitest` 5.1.1, `recharts` 3.11, `lucide-react` 1.77 and others.

## [1.4.2] - 2026-10-29

### Changed

- **Breaking:** the commit watermark is now disabled by default. Repositories that rely on it (for example with `quality-gate verify` in CI) must add `settings.watermark: true` to `quality.yml`. While disabled, no attestation is recorded, `commit-msg` leaves the message untouched, `QG_SKIP` adds no trailer, and the GitHub Action skips the verify step.
- `quality-gate --init` now documents the `settings.watermark` switch in the generated `quality.yml`.

### Documentation

- Added `AGENTS.md` (and a `CLAUDE.md` that imports it) with the branching workflow, project practices and release process.

## [1.4.1] - 2026-10-29

### Added

- `settings.tools_policy` in `quality.yml`: `install` (default) auto-installs missing tools, `recommend` only prints the install command.
- Runtime detection for Go, Python, Node, Rust, PHP and Java, with install hints for macOS, Windows and Linux (`apt-get`, `dnf`, `yum`, `apk`, `pacman`).
- `quality-gate doctor` now checks configured tools and language runtimes, and reports warnings and skipped checks separately from failures.
- `check_environment` MCP tool, sharing the same checks as `doctor`.
- `--init` asks for the project language when none is detected in an interactive terminal.
- `--update` flag to upgrade quality-gate to the latest version.

### Fixed

- `doctor` no longer exits with an error on a fresh clone when a tool will be installed automatically.
- `doctor` no longer reports `npx`, `python -m`, `go run` and similar launcher commands as verified.
- The Python runtime is found as `python` or `py` on Windows.
- The language detector no longer skips its own root directory when it is dot-prefixed.
- The tool-install cache is keyed on the tools policy, and recommendations are no longer silenced by it.

### Dependencies and CI

- Web dashboard dependencies updated, including `next` 16.4.3, `react` 19.3.1, `vite` 8.3, `vitest` 5.0.5 and `shadcn` 4.23 (fixes the `zod` advisory); security advisories for `next`, `proxy-addr`, `@modelcontextprotocol/sdk` and others are resolved.
- Dependabot groups `/web` updates into a single pull request and ignores major bumps of `typescript`, `eslint` and `@types/node`.
- CI now runs on pull requests targeting `develop`.
